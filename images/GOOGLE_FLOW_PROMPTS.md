# Google Flow Image Generation Prompts & Asset Reference Guide
## Project: PROPERTY CONSULTANT (Real Estate Consultancy Demo)

This document provides prompt recipes, aspect ratios, target resolutions, and mapped filenames designed specifically for generating hyper-realistic, photorealistic, architectural, and corporate imagery with **Google Flow** (or Imagen/Midjourney).

---

### Global Aesthetic Parameters for Google Flow Prompts
To maintain a cohesive, high-end, editorial look consistent with the website's **Navy (#172B45)**, **Royal Blue (#285B85)**, and **Warm Gold (#B99A62)** color palette:
- **Style**: Architectural photography, ultra-realistic, shot on Hasselblad H6D-100c, 35mm / 50mm f/1.8 lens, natural golden hour or soft diffused studio lighting, 8k resolution, crisp architectural lines, clean interior styling, editorial real estate publication quality.
- **Atmosphere**: Sophisticated, trustworthy, elegant, clutter-free, premium corporate.
- **Negative prompts (if supported)**: cartoon, 3d render, plastic look, oversaturated, blurry, distorted geometry, warped pillars, fake text, watermarks, bad anatomy.

## 5. How to Integrate the Generated Images into the Codebase

When your Google Flow images are generated, place them inside `assets/images/` using the filenames indicated above.

In each HTML file, replace the placeholder container:
```html
<!-- BEFORE: Placeholder -->
<div class="image-placeholder ratio-16-9">
  <div class="placeholder-icon">...</div>
  <div class="placeholder-title">RESIDENTIAL PROPERTY IMAGE</div>
  <span class="placeholder-tag">Google Flow Import Ready</span>
</div>
```

With the image tag:
```html
<!-- AFTER: Generated Google Flow Image -->
<div class="property-card-image-wrap ratio-16-9" style="overflow: hidden; border-radius: var(--radius-md);">
  <img src="assets/images/property-01.jpg" alt="Premium Apartment – Demo Location 01" style="width: 100%; height: 100%; object-fit: cover; transition: transform 0.4s ease;" loading="lazy">
</div>
```

*(All CSS rules for `.property-card-image-wrap`, ratios, borders, and hover zoom effects are already pre-configured in `css/style.css`.)*
